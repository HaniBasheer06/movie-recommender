# IMDb Style Movie Recommender

A Streamlit-based movie recommendation web app using TMDb API.

## Features
- Search movies from a live database
- Get similar and recommended movies
- IMDb-style dark UI
- Trending movies section
- Poster hover animation
- Genre badges

## Tech Stack
- Python
- Streamlit
- Requests
- TMDb API

## Setup
1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Create a `.env` file:
   ```env
   TMDB_API_KEY=your_api_key_here
   ```
4. Run the app:
   ```bash
   streamlit run app.py
   ```

## Note
Do not upload your `.env` file to GitHub.
